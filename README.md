# The Funniest Honest Appliance Error

`It's not the thermostat. It's the pump. It's been the pump since March. Stop turning the thermostat up and blaming me.`

Run it with `node main.ts` — the program prints the single entry line to stdout.

The boiler calls out the homeowner's denial: everyone keeps turning up the thermostat when the pump is the real culprit, and the machine is tired of taking the blame. It echoes every winter where you wake up freezing, crank the dial, and wonder why the radiators stay cold while the boiler just clicks uselessly — the pump has been dead for weeks and no amount of wishful thinking will push hot water through the pipes.
